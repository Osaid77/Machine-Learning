# Machine Learning Projects

A collection of healthcare-focused Python projects built while developing strong foundations in Python programming and software engineering. This shows that all my understanding of Python was built on the healthcare industry.

## Projects
### 1. Hospital Readmission prediction
A machine learning model to predict readmission within 30 days after discharge. We use multiple classifiers to predict our target including the dummy classifier. Data is split into 70% training, 15% validation, and 15% for testing and only 1 record per patient is allowed. Class imbalance is spotted as the positive class labels represents only 8.79% of the dataset. [View project](./hospital-readmission-prediction)
