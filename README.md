# Machine Learning Projects

A collection of healthcare-focused ML projects built while developing strong foundations in Machine Learning engineering. This shows that all my understanding of ML was built on the healthcare industry.

## Projects
### 1. Hospital Readmission prediction
A machine learning model to predict readmission within 30 days after discharge. We use multiple classifiers to predict our target including the dummy classifier. Data is split into 70% training, 15% validation, and 15% for testing and only 1 record per patient is allowed. Class imbalance is spotted as the positive class labels represents only 8.79% of the dataset. [View project](./hospital-readmission-prediction)


### 1. In-hospital Mortality prediction
A machine learning model to Predict in-hospital mortality using clinical information collected within first 24 hours of hospitalization. I use multiple classifiers to predict our target including the dummy classifier. Data is split into 70% training, 15% validation, and 15% for testing and data is already unique i.e. each record represents a different patient. Class imbalance is spotted as the positive class labels represents only 8.63% of the dataset. [View project](./in-hospital-mortality-prediction)
